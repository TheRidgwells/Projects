Privacy Policy

This site is static and built to be private by default. It never sends your data anywhere.

Effective: October 2026 — Last updated: November 2026

The short version

The Ridgwell Family Projects is a static site — plain HTML, CSS, and JavaScript with no server-side application behind it. There is no account system, no database, and no form on this site that sends data anywhere.

Personal data None is collected by this site. We don't ask for your name, email, or any identifying information.
Cookies & tracking None. No analytics scripts, no tracking pixels, no third-party ad networks. See the Cookies Policy for the two optional preferences kept in your browser.
Hosting This site is hosted on GitHub Pages. GitHub, as the hosting provider, may log standard web server data (IP address, request path, timestamp) per its own privacy policy — that logging happens at the infrastructure level, not something this site controls or receives. The live status at the top of the home page is read from Ridgwell Status’s data file, also on GitHub (raw.githubusercontent.com), which can log the same kind of data for that request.
Fonts, scripts and styles All served from this site itself. The fonts (Lato and Poppins) are self-hosted, so there are no requests to Google Fonts or any other font or script CDN.
What loads from elsewhere The Ridgwell Family logo and icon (in the header and footer) load from global.media.ridgwell.family, the family’s own media host (files stored on DigitalOcean Spaces and served through Cloudflare). Like any image request, it carries your IP address and browser details; it sets no cookies and nothing on it identifies you. Every page loads the cat that follows your pointer from kat.stuxie.dev (StuxieDev, Leo’s own site); that request carries no cookies and nothing that identifies you. The home page also loads the seasonal overlay animation from SeasonalOverlaysLibrary on seasonaloverlayslibrary.stuxapis.net (StuxAPIs); that request carries no cookies and nothing that identifies you. Nothing else loads from anywhere but this site.
Advertising None. This site carries no ads and sells no data.

Linked sites

Each project listed here links out to its own website (and, for some, a GitHub repository), which may have their own privacy practices. This policy covers only The Ridgwell Family Projects index site itself.

Children's privacy

This site does not knowingly collect information from anyone, children included — it doesn't collect information from anyone at all.

Changes to this policy

If this policy changes in any meaningful way, the date above will be updated.
